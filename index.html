    5. Analisis Script Tanpa Atribut defer di Bagian <head>

    Apabila tag <script src="script.js"></script> diletakkan di dalam <head> tanpa atribut defer, browser akan langsung mengeksekusi file JavaScript sebelum elemen-elemen di dalam <body> selesai diparsing. Akibatnya, pemanggilan document.getElementById() mengembalikan null dan memicu error Uncaught TypeError: Cannot set properties of null (setting 'textContent') atau Cannot read properties of null (reading 'addEventListener').
